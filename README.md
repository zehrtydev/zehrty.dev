# Zehrtydev — Portfolio

Nueva web personal de Manuel Amado / Zehrtydev, construida desde cero con Next.js y TypeScript.

## Stack

- Next.js 15
- React 19
- TypeScript
- CSS global personalizado
- react-icons

## Ejecutar localmente

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`.

## Producción

```bash
npm run build
npm start
```

## Contenido

- Hero con identidad Zehrtydev
- Producto destacado: Moni
- Flujo de automatización y revisión humana
- Perfil profesional y formación
- Contacto
- Responsive desktop/tablet/mobile
- Animaciones respetando `prefers-reduced-motion`

## Notas

El dashboard de Moni es un mockup HTML/CSS temporal. Cuando estén listas las nuevas capturas reales de Moni, puede reemplazarse por screenshots o una composición más fiel del producto.
